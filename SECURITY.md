# Security Policy

This is a private, pre-release research and engineering repository.

## Sensitive Material

Never commit credentials, API keys, bearer tokens, private keys, connection strings, signed URLs, SAS query parameters, local environment files, model API response caches, or machine-specific absolute paths. Signed retrieval URLs may exist only in process memory and must be redacted before logging or provenance capture.

Full runtime directories, raw HTTP responses, raster assets, and AOI chips remain ignored until licensing, disclosure, and secret review are complete. Do not delete local evidence merely because it is ignored.

## Reporting

Report a suspected leak privately to the repository owner. Do not open a public issue or paste the material into chat, logs, commits, or CI output. Rotate exposed credentials before history remediation.

No security support window or public vulnerability disclosure programme is promised while the repository remains private and unlicensed.
