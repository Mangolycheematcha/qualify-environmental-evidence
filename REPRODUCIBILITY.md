# Reproducibility

## Environment

- Python 3.10 or later.
- Dependencies declared in `pyproject.toml`.
- Offline tests require only cached packages and static repository fixtures.

## Contract Validation

```text
uv run --offline --no-project --with "jsonschema>=4.18,<5" python scripts/validate_step1_specs.py
uv run --offline --no-project --with "jsonschema>=4.18,<5" python skill/qualify-environmental-evidence/scripts/qualify.py --check-resources --json
uv run --offline --no-project --with "jsonschema>=4.18,<5" --with "pytest>=8,<9" --with "pyyaml>=6,<7" python -m pytest -o addopts="" -p no:cacheprovider -q
uv run --offline --no-project python scripts/package_skill.py --check
```

## V4 Proposal

`scripts/propose_v4.py` derives V4 from the immutable V3 bytes using structured JSON operations and deterministic serialization. `--check` fails if the checked-in proposal differs from regenerated bytes and prints its SHA-256.

V4 remains `PENDING_HUMAN_APPROVAL`, has `runtime_ready=false`, contains no approved policy hash, and has no detached approval or live run directory.

## V3 Integrity

The accepted V3 policy and run hashes are pinned in tests. The original run remains under ignored local `runs/`; the reviewed derivative under `examples/` is not a substitute for the complete evidence package.
