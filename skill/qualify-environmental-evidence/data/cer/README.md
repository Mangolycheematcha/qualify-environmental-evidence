# CER Public Evidence Snapshots

These files are small, curated, source-attributed fact snapshots used by the offline qualification demo. They are not raw CER pages, complete register exports, legal records, or substitutes for checking the current official source.

- Seven `*-project-record.json` files record selected public facts from seven official ACCU project pages across six method categories, as accessed on 2026-09-05.
- `safeguard-2024-25-arcadia.json` records one selected facility-period row from the official CER 2024-25 Safeguard CSV. Its `SMCs issued` field is a source restatement, not independent proof of issuance.
- `accu-smc-public-definitions.json` records the CER's public distinction between ACCUs and SMCs as accessed on 2026-09-05.
- `corpus-manifest.json` binds every curated snapshot to its official URI, access date, source byte count, source-content hash, and local snapshot hash.

The snapshots preserve canonical source URLs and retrieval dates. They contain no credentials, personal contact details, signed URLs, raster data, or complete source payloads.
