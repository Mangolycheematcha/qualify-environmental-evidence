# Contribution Policy

This repository is private and has no selected licence. Contributions require explicit owner permission and do not grant public reuse rights.

Changes must preserve immutable policy and run artifacts, keep evidence identity separate from temporary retrieval credentials, add deterministic tests for contract behavior, and fail closed when metadata or provenance is unresolved. Environmental outcomes must never influence source selection, grouping, thresholds, masks, windows, or policy wording.

Before proposing a commit, run the complete validator, test suite, package drift check, standalone package test, skill quick validation, and secret/path/signed-URL audits. Do not add raw source payloads or raster data without documented licensing and disclosure review.
