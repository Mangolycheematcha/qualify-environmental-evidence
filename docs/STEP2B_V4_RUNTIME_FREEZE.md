## Frozen Execution

The runtime verifies the clean Git baseline, exact detached approval, policy bytes, runtime-spec bytes, implementation-file hashes, CPython version, and exact NumPy/Rasterio versions before network access. Version `1.0.2` retains at most three attempts per request with frozen delays of 0, 2, and 5 seconds, makes raw `TimeoutError` retryable, and persists `network_accessed=true` before the first request. It also records attempt counts, parses JSON to distinguish non-finite numeric values from strings, and preserves the primary runtime reason if failure sealing encounters a secondary error.

The live sequence is:

1. retrieve and verify CER project and CEA sources;
2. complete both frozen STAC searches without a cloud predicate;
3. apply the 200-item metadata inventory limit;
4. fetch signed product/granule metadata without persisting credentials;
5. resolve representations, metadata admissibility, and independent acquisitions;
6. apply the 40-acquisition gate before raster pixels;
7. process all admissible groups on the frozen AOI grid;
8. calculate coverage, NDVI aggregation, primary disposition, and separate sensitivities;
9. seal the canonical assessment;
10. recompute NDVI and disposition from unsigned AOI-level B04/B08/SCL caches in explicit offline replay mode;
11. validate provenance, scan outputs, and write checksums.

Any implementation or deterministic processing failure is preserved and cannot resume under the same run ID. The runtime does not start Step 3.
